# 🌙 Ramadan Schedule 2026 — North Bengal
(পবিত্র মাহে রমযান ১৪৪৭ হিজরী - উত্তরবঙ্গ)

A modern, responsive, and lightweight web application designed to provide accurate **Sehri and Iftar timings** for **Gaibandha** and surrounding **North Bengal districts** for the holy month of Ramadan 2026.

![Project Preview](https://rangpur-roza.vercel.app/assets/img/preview.jpg)

## ✨ Features

- **📍 Multi-District Support**: Easily switch between 8 major districts of North Bengal.
- **⏱️ Real-time Countdown**: Accurate countdown timer for the next Sehri or Iftar.
- **📅 Dynamic Schedule**: Automatically highlights today's date and time.
- **🕌 Ashra Information**: Displays the current Ashra (Rahmat, Maghfirat, Nazat) based on the date.
- **💾 Smart Caching**: Remembers your selected district and caches data for instant loading (offline-friendly feel).
- **📱 Fully Responsive**: Optimized for both mobile phones and desktop screens with a beautiful, clean UI.
- **🎨 Modern Design**: Soft, eye-comfortable light theme with Islamic aesthetics.

## 🗺️ Supported Districts

1.  **Gaibandha (গাইবান্ধা)**
2.  Rangpur (রংপুর)
3.  Kurigram (কুড়িগ্রাম)
4.  Lalmonirhat (লালমনিরহাট)
5.  Nilphamari (নীলফামারী)
6.  Dinajpur (দিনাজপুর)
7.  Thakurgaon (ঠাকুরগাঁও)
8.  Panchagarh (পঞ্চগড়)

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom variables, Grid/Flexbox layout, and sticky headers.
- **JavaScript (ES6+)**: Dynamic DOM manipulation, Fetch API for data loading, and LocalStorage for user preferences.
- **FontAwesome**: For icons.
- **Google Fonts**: 'Noto Serif Bengali' for beautiful typography.

## 🚀 How to Run

No build tools or complex servers required!

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/ramadan-schedule-2026.git
    ```
2.  **Open `index.html`** in your browser.
    - Or use a local server like **Live Server** in VS Code for the best experience.
